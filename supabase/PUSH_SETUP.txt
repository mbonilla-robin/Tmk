ROBIN — Activar notificaciones push (Web Push)
================================================

Esto conecta las notificaciones de robin_notifications con el teléfono/escritorio
de cada usuario cuando tienen la PWA instalada.

1) Aplicar migración en Supabase
--------------------------------
Ejecuta la migración:
  supabase/migrations/20260629140000_robin_push_subscriptions.sql

Desde el panel: SQL Editor → pegar el contenido → Run.

2) Claves VAPID — CONFIGURADAS EN LA FUNCIÓN (v2)
-------------------------------------------------
La Edge Function incluye las claves VAPID por defecto (coinciden con js/config/push.js).
Opcional: puedes sobreescribirlas en Supabase → Edge Functions → Secrets.

3) Edge Function — DESPLEGADA (v2)
----------------------------------
  send-push-on-notification (verify_jwt = false)

4) Migración robin_push_subscriptions — APLICADA
------------------------------------------------

5) Webhook automático — APLICADO VÍA TRIGGER
---------------------------------------------
Trigger `robin_push_on_notification_insert` en `robin_notifications` (pg_net).
Cada INSERT dispara la Edge Function sin configuración manual en el panel.

5) Probar en un teléfono
------------------------
1. Abre ROBIN en HTTPS (no file://).
2. Instala la PWA en la pantalla de inicio (iOS) o “Instalar app” (Android).
3. Inicia sesión como el usuario destino (ej. ralvarez).
4. Acepta “Activar” en el banner de notificaciones.
5. Desde otro usuario (ej. mbonilla), menciona @R Álvarez en un comentario.
6. Debería llegar un push del estilo:
   "Miguel Bonilla te dejó este comentario: \"...\""

Notas iOS
---------
- Push en PWA solo funciona con la app instalada en Inicio (iOS 16.4+).
- El permiso debe concederse después de instalar la PWA.

Notas Android / Desktop
-----------------------
- Chrome/Edge/Firefox soportan Web Push en HTTPS.
- En desktop también funciona sin instalar, pero conviene tener la PWA abierta
  al menos una vez para registrar el service worker.
